# Social Planner — Pinterest + Instagram

## Specs
| Format | Size | Text limits |
|---|---|---|
| Pinterest pin | 1000×1500 (2:3) | Title ≤100, description ≤500, alt text ≤500 |
| Pinterest video pin | 1080×1920 (9:16), 6–15 s | same |
| Instagram post / carousel | 1080×1350 (4:5) | caption ≤2200 (hook in first 125 chars), ≤30 hashtags (use 5–10) |
| Instagram reel | 1080×1920 (9:16), 7–30 s | caption as above |

## Cadence (small shop default)
Pinterest: 5–10 fresh pins/week (new image or new text on the same listing), spread over keyword boards. Instagram: 3 posts + 1–2 reels/week.

## Content mix
40% product in a room · 20% process / making / artisan story · 20% tips (size guide, care, styling) · 10% social proof (real reviews only, with no buyer names unless permitted) · 10% offers / occasions.

## Pinterest SEO
Board names = search phrases ("Boho Living Room Rugs", "Nursery Rug Ideas"). Pin title = keyword phrase + benefit. Description = 2–3 natural sentences with keywords + CTA. Link = the listing (Etsy Share & Save link earns the 4% credit).

## Calendar row format
```
| Date | Platform | Format | Listing | Visual brief (→ creative-agent) | Title / Caption | Hashtags | Link |
```
Links stay as `[LISTING URL]` in anything tracked; real URLs only in `data/`.

## Posting
Posting is a live change → proposal per batch of posts (one card per week's calendar is fine, listing each post).
