# Home Decor & Textiles — Domain Knowledge (non-rug categories)

Use this file in place of `.claude/skills/domain/rugs.md` when the product is not a rug. Every skill works the same way; only the product-specific fields change. If a product type isn't listed, apply the "Any other product" pattern at the bottom.

## What replaces the rug fields

| Rug field | Equivalent for other products |

| Sizes (2x3 … 9x12) | The category's standard sizes (below), inches **and** cm |

## Materials & care

| Material | Words to use | Care line | Watch out |
|---|---|---|---|
| Cotton (voile, cambric, canvas, percale) | breathable, soft, lightweight | Machine wash cold, gentle; line dry | State GSM / thread count if known; may shrink 3–5% |
| Linen | textured, airy, gets softer with washing | Machine wash cold; wrinkles are natural | Don't call cotton-linen blends "pure linen" |
| Wool | warm, natural | Dry clean / hand wash cold | Itch level, shedding |
| Silk / viscose | sheen, drape | Dry clean only | Disclose viscose ("art silk") honestly |
| Jute / seagrass / cane | natural, textured | Wipe / shake out, keep dry | Not for damp rooms |
| Velvet | plush, rich | Dry clean / spot clean | Cotton vs polyester velvet — say which |
| Hand block / natural dye | artisanal, slight irregularities are the charm | Wash separately the first time; colors may bleed slightly | Never claim "colorfast" or "organic dye" without proof |

## Photo set (10 photos) for non-rug items

1 hero on clean background · 2 styled in room/use · 3 second room or use · 4 scale shot (on bed/sofa/table with known objects) · 5 fabric/texture close-up · 6 detail (stitching, zipper, edge, print repeat) · 7 size chart graphic · 8 folded / stacked / set laid out · 9 packaging / gift-ready · 10 lifestyle or color options. Same "real product, unchanged" rule as rugs for AI-assisted images.

## Keyword pattern

`[technique] + [material] + [product]` → "block print cotton tablecloth" · `[color/pattern] + [product] + [size]` → "blue floral quilt queen" · `[room/use] + [product]` → "farmhouse kitchen towels" · `[occasion] + gift` → "housewarming gift". Set quantity ("set of 4") and size belong in the title for sets and bedding.

Create one keyword pool per product type in `data/keyword-pools/` from `templates/keyword-pool.md` (same sections as the rug pools).

## Occasions that fit textiles & decor (Western calendar)

Thanksgiving / holiday table (tablecloths, napkins, runners) · Christmas gifting · Mother's Day · wedding & bridal shower · housewarming · spring refresh · summer outdoor/patio · back-to-school dorm (bedding, throws, pillows) · nursery / baby shower (quilts, blankets).

## Any other product

Ask (or read from the shop profile): what it is · technique · material · dimensions (in + cm) · weight · variations (size / color / set) · care · who/where it's for · what's customizable. Then apply the same listing structure: title (primary phrase in first 40 chars) → 13 tags → attributes → description (hook, details, sizes + prices, care, shipping, custom CTA, FAQ) → 10 photos + alt text.
